## 🚀 我的项目

### [AgentX - 智能对话 Agent 构建平台](https://github.com/conversition/AgentX_ccc_test)

基于 **LLM + MCP 协议** 的智能 Agent 构建平台:

- 🏗 **DDD 四层架构**:Spring Boot 3 后端(interfaces / application / domain / infrastructure)
- ⚛️ **Next.js 15 + TypeScript** 前端,支持 Agent 工作台、工具市场、知识库
- 🧠 **RAG 知识库** + 长期记忆 + 滑动窗口/摘要上下文管理
- ⏰ 定时任务、计费系统(Product → Rule → Strategy)、模型高可用网关
- 🧪 13 个 JUnit 测试类 + CI 流水线(格式检查 / Docker 构建)
